# sugar-intel

Plataforma de inteligência de mercado do complexo sucroenergético brasileiro —
açúcar, etanol, safra, clima e vetores macro, em painéis interativos.

**Acesse:** https://strongylis.github.io/sugar-intel/

## O que há na plataforma

| Seção | Painéis |
|---|---|
| Visão geral | Faixa de KPIs — spot, futuros, câmbio, paridade na bomba, ENSO |
| Clima | INMET COSMO-7 + radar IPMet (SP) · previsão de chuva 14 dias · NMME (anomalia mensal) · ENSO / ONI |
| Açúcar | ICE nº 11 (safra, semanal, curva forward e spreads) · posicionamento CFTC · cristal CEPEA/ESALQ · base ESALQ−NY · balanço USDA |
| Etanol | Hidratado PVU Ribeirão + futuros B3 · curva B3 · CEPEA SP/GO · paridade na bomba por estado (ANP) · ciclo Otto · defasagem ABICOM |
| Safra | Desempenho quinzenal e acumulado (UNICA / MAPA) · oferta e demanda de etanol · CONAB |
| Macro | Brent · WTI · USD/BRL PTAX (anual e semanal) · painel de commodities |

Cada painel indica a **fonte primária** do dado (CEPEA/ESALQ, UNICA, MAPA, CONAB,
ANP, ABICOM, CFTC, USDA, NOAA, IPMet/UNESP, INMET, BCB, Federal Reserve Bank of
New York, ICE, B3, Open-Meteo, Finviz).

## Como funciona

A plataforma é servida como página estática, sem servidor de aplicação e sem
rastreamento. Os dados são atualizados periodicamente a partir das fontes
oficiais listadas em cada painel.
